K4 design (from the mechanism analysis, now the committed plan): add a segment-descriptor input to the fused chunk kernels so the alternate tree segment restarts INSIDE the dispatch — the closed-form branch seed is exactly the kernel's chunk-end update, so the kernel computes segment 1's end state, derives the branch-point prefix state, and continues into segment 2 without a host round-trip. Host-composed restart measured ~2 ms (break-even); in-kernel target 0.3-0.5 ms. Everything host-side already landed (propose_branching, forward_tree, tree_check, tree_band). Tree default stays OFF until K1 + this land and the end-of-fuse pass shows EV-positive on the rebuilt table.

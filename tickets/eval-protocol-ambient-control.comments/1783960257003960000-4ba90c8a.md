AMENDMENT 5 — MICRO-HARNESS VALIDITY DOMAIN (2026-07-13, referee-session finding): isolated micro benches are valid kernel evidence ONLY for shapes whose working set exceeds the SLC (i.e., genuinely DRAM-bound — on our shapes, the 143MB head; NOT the 1-5MB body shapes). Mechanism, measured: per-eval sync overhead ~150us floors small-shape per-call rates (MLX per-call matched our harness within noise on every body shape), while chained reruns of the same shapes hit 195-266 GB/s on a 150 GB/s machine — the weights are SLC-resident, so the bench measures cache, not memory. RULES: (a) small-shape kernel claims go through production A/B only; (b) any future micro task must state which side of the SLC boundary its working set sits on; (c) when comparing against third-party harnesses, match amortization mode (per-call vs chained) or the comparison is harness-vs-harness.

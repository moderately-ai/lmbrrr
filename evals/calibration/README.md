# MiniCPM-V-4.6 Quantization Calibration

This directory stores deterministic calibration metadata for MiniCPM-V-4.6
quantization experiments. The primary artifact is:

```text
evals/calibration/minicpm_v46_quant_calibration.jsonl
```

Each JSONL row is one calibration prompt with:

- the MiniCPM chat-template rendered prompt;
- token ids from the repo-local tokenizer metadata;
- the thinking mode used for generation;
- text, image, or video modality metadata;
- expected behavior notes for later regression checks;
- sensitivity-focus tags for module-level quantization scoring.

Regenerate the fixture with the `uv` project environment:

```sh
uv run python evals/generate_minicpm_v46_quant_calibration.py \
  --output evals/calibration/minicpm_v46_quant_calibration.jsonl
```

The generator uses:

```text
docs/research/models/minicpm-v-4.6/hf-model/tokenizer.json
docs/research/models/minicpm-v-4.6/hf-model/chat_template.jinja
```

Do not hand-edit token ids. Add or modify cases in
`evals/generate_minicpm_v46_quant_calibration.py`, then regenerate the JSONL.

Media rows intentionally store descriptors only. They name future deterministic
media paths under `evals/calibration/media/`, but this ticket does not commit
image or video bytes. The image/video assets should be generated by later
multimodal eval tooling so the JSONL remains small and reviewable.
